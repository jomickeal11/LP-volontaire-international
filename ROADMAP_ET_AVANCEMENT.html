🎯 3. Ce qu'il reste à faire pour finaliser à 100%

1

Stockage Cloud des Fichiers pour la Production

Les fichiers sont actuellement stockés dans le dossier local /uploads. C'est idéal en local, mais pour un hébergement serverless (Vercel), un stockage objet persistant est requis.

  • Connecter un bucket persistant (Cloudflare R2, Supabase Storage ou AWS S3).
  • Conserver la route d'API de streaming sécurisé existante pour protéger les documents personnels.
Priorité Haute
2

Déploiement en Production & Mise en Ligne

Mise en ligne finale de la plateforme sur son infrastructure définitive et sécurisée.

  • Héberger la base PostgreSQL en ligne (ex: Supabase / Neon).
  • Déployer l'application web Next.js (Vercel ou VPS Ubuntu avec Docker).
  • Configurer le nom de domaine officiel avec certificat SSL (HTTPS).
  • Renseigner la variable NEXT_PUBLIC_GA_ID dans les variables de production.
Mise en Prod
3

Assignation des dossiers à un coordinateur

La colonne assignedToId existe déjà en base de données Prisma, il reste à l'exposer dans l'interface de la fiche candidat dans l'admin.

  • Ajouter un sélecteur dans la fiche candidat pour assigner le dossier à un membre de l'équipe.
  • Ajouter un filtre par coordinateur dans la liste des candidatures.
Priorité Moyenne
